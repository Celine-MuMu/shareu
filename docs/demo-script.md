# MVP 展示腳本（3 分鐘）

> T6.1、T7.5　依據：requirements.md v1.7
> 一條故事線走完四位 persona：**Mia 租 → Kevin 找 → Amy 被擋、問物主 → Jason 賺錢、回訊息 → Mia 歸還互評 → 贊助**
> 「台詞」是建議說法，可以照自己的習慣改

---

## 上台前檢查（5 分鐘前）

- [ ] 用 Chrome 打開網站（GitHub Pages 網址），**要有網路**，首頁輪播的照片才載得出來
- [ ] 首頁滑到最下面，按「**重設展示資料**」→ 確定（把彩排時建立的訂單、上架、贊助清掉）
- [ ] 右上角是「登入」（沒有登入任何人）；語言是**中文**
- [ ] 瀏覽器縮放 100%～125%，投影時字才夠大
- [ ] 如果用手機展示：先「加到主畫面」，用全螢幕開

---

## 0:00–0:20　開場：首頁

**操作**：停在首頁，讓輪播自己換一輪

**台詞**：
> 這是 ShareU，Share with U。演唱會、出國交換、課業作品，這三個場景的東西都很貴、又只用幾次。我們讓同學之間互相租，在校園置物櫃取件。

---

## 0:20–1:05　Mia：租一支演唱會手機

| 步驟 | 操作 | 畫面上要指給大家看的 |
|---|---|---|
| 1 | 點「演唱會」場景卡片 | 自動篩選好演唱會的物品 |
| 2 | 點 **Samsung Galaxy S25 Ultra** | 「ShareU 官方」金色標籤＝平台自有的手機 |
| 3 | 按「我要租」 | 沒登入會先帶去登入 |
| 4 | 在「快速切換身分」點 **Mia** | 學校信箱認證，登入後自動回到租借頁 |
| 5 | 日期用預設的；勾「加購損壞保障」 | 押金 ~~NT$2,000~~ → **NT$500**，下面寫為什麼打折 |
| 6 | 按「前往付款」→「確認付款」 | 置物櫃**取件碼** |

**台詞**：
> Mia 是新聞系大二，搶到演唱會門票，但手機在後排拍不清楚。她用學校信箱登入，租兩天只要七百塊。因為她評價很好、又加購了保障，押金從兩千降到五百。付款後拿到取件碼，週五直接去圖書館的置物櫃拿。

---

## 1:05–1:20　Kevin：找交換要用的行李箱

| 步驟 | 操作 | 要指的 |
|---|---|---|
| 1 | 點下面的「找東西」 | |
| 2 | 搜尋框打「**行李箱**」 | 打字就馬上篩出來 |
| 3 | 點「篩選」→ 標籤「**可長租**」 | 篩選條件可以疊加 |
| 4 | 指著 **28 吋大行李箱 NT$15 / 天** | 卡片右邊的「九成新」＝成色 |

**台詞**：
> Kevin 下學期要去德國交換。一個好的行李箱要五千塊，回國後房間也沒地方放。在 ShareU 跟畢業的學姐租，一天十五塊，租五個月也才兩千多。

---

## 1:20–1:55　Amy：信任機制＋問物主

| 步驟 | 操作 | 要指的 |
|---|---|---|
| 1 | 右上角頭像 →「快速切換身分」點 **Amy** | Amy 是大一新用戶，還沒有評價 |
| 2 | 找東西 → 搜尋「**Sony**」→ 點 **Sony A7 IV** | 成色「八成新」、2022 年購入；黃色提示：只租給評分 4 分以上 |
| 3 | 按「我要租」 | 被擋下來，引導她先租其他東西累積評價 |
| 4 | 按「返回」→ 按「**問物主**」 | 像 LINE 的聊天室 |
| 5 | 點快速問題「**可以教我怎麼用嗎？**」 | 一秒後 Jason 自動回覆「取件時帶你設定」 |

**台詞**：
> 那物主怎麼放心把三萬塊的相機借給陌生人？除了學校信箱認證，物主可以設定只租給評分高的同學。Amy 是新用戶，所以先被擋下來。不過她還是可以先問物主，第一次拍片不會用也沒關係，物主可以教她。

---

## 1:55–2:30　Jason：把閒置器材變收入

| 步驟 | 操作 | 要指的 |
|---|---|---|
| 1 | 切換身分點 **Jason** | |
| 2 | 點下面的「**上架**」 | |
| 3 | 名稱打「降噪耳機」、場景選「出國交換與旅行」、類別選「收音設備」 | 類別也可以選「其他」自己打；成色、購入年份用選的 |
| 4 | 每日租金打「**60**」 | 馬上顯示「你每天實拿 NT$54」（扣 10%） |
| 5 | 勾一個取件點 → 按「上架」 | 直接跳到物品頁 |
| 6 | 點「我的」→「**我的上架**」 | 深藍框裡的**預計總收入**、每筆訂單的收入 |
| 7 | 點「**訊息**」分頁 | 看到 Amy 剛剛問的問題，可以點進去回覆 |

**台詞**：
> Jason 快畢業了，相機和 GoPro 大部分時間都在抽屜裡。上架只要一分鐘，平台抽一成，他看得到每一筆收入，也收得到同學問的問題。

---

## 2:30–2:48　Mia：歸還、互相評價

| 步驟 | 操作 | 要指的 |
|---|---|---|
| 1 | 切換身分點 **Mia** →「我的」→「我的租借」 | 剛剛那筆訂單「待取件」 |
| 2 | 按「下一步：已取件」→「下一步：已歸還」 | （展示用，平常是置物櫃自動更新） |
| 3 | 按「評價 ShareU」→ 點 5 顆星 → 送出 | 評價會讓對方的分數更新 |

**台詞**：
> 演唱會結束，Mia 把手機放回置物櫃，押金退回，雙方互相評價。評價越好，下次押金越少。

---

## 2:48–3:00　結尾：關於我們＋贊助

**操作**：點「關於我們」→ 滑到最下面「贊助我們」

**台詞**：
> 我們第一步會在政大做 MVP 測試。如果喜歡這個想法，也歡迎在這裡支持我們。謝謝大家！
