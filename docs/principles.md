# 專案原則

> 狀態：✅ 已確認（2026-10-22）

## 目標

做出 **ShareU** 的 MVP 網站：讓學生向同學租借昂貴、又不常用的物品。
這個版本是要在 pitch 簡報最後「MVP 展示」時現場操作用，**先不接資料庫**，資料用假資料＋存在瀏覽器裡。

## 原則

1. **先規格、後程式**：照「原則 → 需求 → 設計 → 任務 → 程式」的順序走。文件沒確認，不寫程式。
2. **改需求要先改文件**：中途想加功能或改東西，先更新 `requirements.md`，再改程式。
3. **保持簡單**：只用 HTML、CSS、JavaScript，不用框架、不用安裝工具，用 VS Code 打開就看得懂。
4. **先不用資料庫**：所有資料集中在 `data.js`（假資料）和 `store.js`（存取），之後要換成真的資料庫只改 `store.js`。
5. **展示優先**：功能以「上台 3 分鐘能走完一個 persona 的故事」為準，不追求完整。
6. **手機和投影都要好看**：手機優先設計，但在電腦／投影幕上也要排得好。
7. **小步前進**：一次做一個任務，做完、在瀏覽器試過、打勾，再做下一個。
8. **看得懂**：程式碼加中文註解。
9. **不用 emoji 當 icon**：介面一律用線條 icon（Lucide）。
