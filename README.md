# ShareU

**Share with U**：校園租借平台的 MVP 網站。學生向同學租借昂貴、又不常用的物品，在校園置物櫃取件。

## 怎麼打開

- 本機：在 Finder 對 `index.html` 按兩下，用瀏覽器打開就可以了，不用安裝任何東西
- 線上：GitHub Pages（網址見下方）

## 展示

- 展示腳本：`docs/demo-script.md`（3 分鐘，四位 persona）
- 上台前先到首頁最下面按「重設展示資料」

## 檔案

- 規格文件在 `docs/`：`principles.md` → `requirements.md` → `design.md` → `tasks.md`
- 假資料（物品、價格）在 `data.js`；改完要按「重設展示資料」才看得到
- 這是展示版：沒有資料庫、沒有真的金流，資料都存在瀏覽器裡
